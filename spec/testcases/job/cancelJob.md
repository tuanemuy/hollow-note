# テストケース: cancelJob

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 待機中のジョブ | キャンセルする | `canceled` になる | |
| 実行中のジョブ | キャンセルする | `canceled` になる | |
| 成功したジョブ | キャンセルする | `BusinessRuleError(JobNotCancelable)` が投げられる | |
| 失敗したジョブ | キャンセルする | `BusinessRuleError(JobNotCancelable)` が投げられる | |
| 親ジョブで待機中の子が 5 件、実行中が 2 件 | キャンセルする | 待機中の 5 件が取り消され、実行中の 2 件は完了を待つ | |
| 一括ダウンロードのジョブ | キャンセルする | 中間生成物が破棄される | |
| 取り込みジョブをキャンセルする | キャンセルする | それまでに作られたノートは残る | |
| 再生成ジョブをキャンセルする | キャンセルする | ノートの本文は変更前のまま維持される | |
| `kind: "conversion"` のジョブで対象ノートが `processing` のまま | キャンセルする | 「共通: 強制終端の後始末」に従い `Note.markConversionFailed("canceled")` がジョブの終端と**同一 UoW** で保存され、ノートが `failed(canceled)` になる（`processing` のまま固定されて移動も作り直しもできなくなるのを防ぐ） | |
| `kind: "regeneration"` のジョブ | キャンセルする | 本文は `ready` のまま変更されない（後始末の対象は `conversion` のみ） | |
| `kind: "pdfExport"` / `bulkExport` / 一括操作系のジョブ | キャンセルする | `content.status` を動かす kind ではないため、ノートの本文状態は変わらない | |
| 対象ノートが既にゴミ箱・完全削除済み | キャンセルする | `ActiveNote` でないため本文の回復は行わず、ジョブの終端だけが保存される | |
| 単体ジョブ（batch 親ではない）をキャンセルした | 破棄された生成物を確認する | 生成物の回収は起きない。`Job.cancel` が受け取るのは `QueuedJob \| RunningJob` で、`artifact` を持つのは `succeeded` のジョブだけだからである（「共通: 強制終端の後始末」の 2 — 回収の対象は、まだ終端していない親の既に成功した子の生成物だけ） | |
| batch 親をキャンセルした（成功済みの子が artifact を持つ） | キャンセルする | `JobRepository.listChildren` で引いた子のうち `succeeded` のものの artifact **だけ**を集めて `deleteFiles`（Storage）で破棄し、ジョブの終端と同一 UoW で保存する（一括ダウンロードの中間生成物が要求者の個人ストレージに 7 日残らない） | |
| 成功して終端済みのジョブが持つ生成物（単体の PDF、匿名の PDF、組み立て済みの ZIP） | 別のジョブをキャンセルする | この規則では回収しない。強制終端は未終端のジョブしか止めないため終端させる集合に入らず、回収は `collectExpiredArtifacts` による期限経過の自動回収に委ねられる | |
| 回収対象の絞り込み | 破棄されたファイルを確認する | 破棄されるのは `purpose: "artifact"` だけで、元ファイル（`source`）や媒体（`media` / `reference`）には触れない | |
| キャンセルと同時に走っていたワーカーが、そのあと artifact を保管した | 保管ファイルを確認する | 強制終端の時点では存在せず終端させた側から見えないため回収されず、期限付き保管の自動回収（`collectExpiredArtifacts`）に委ねられる | |
| 他の利用者のジョブ | キャンセルする | `NotFoundError("JOB_NOT_FOUND")` が投げられる | |
| 匿名ジョブ（`requestedBy: null`） | キャンセルする | 所有の確認で `NotFoundError("JOB_NOT_FOUND")` が投げられる | |
| 匿名の PDF 書き出しが動いているノート | そのノートをゴミ箱へ移す | `trashNote` の対象で引くキャンセル網（`listActiveByTarget`）に匿名ジョブも含まれ、取り消される | |
| 匿名の PDF 書き出しが動いているノート | ワークスペースを削除する・退会する | スコープで引くキャンセル網（`listActiveByScope`）に匿名ジョブも含まれ、取り消される（匿名ジョブの `scope` は対象ノートの所有文脈から導かれるため） | |
| キャンセル後 | 内訳を確認する | 完了と取り消しの件数が分かる | |
