# テストケース: pruneJobHistory

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 91 日前に終了したジョブがある | 実行する | 削除される | |
| 89 日前に終了したジョブがある | 実行する | 残る | |
| ちょうど 90 日前に終了したジョブ | 実行する | 残る（境界値） | |
| 実行中のジョブがある | 実行する | 削除されない | |
| 待機中のジョブがある | 実行する | 削除されない | |
| 親ジョブが削除対象になる | 実行する | 子ジョブも一緒に削除される | |
| 対象が 0 件 | 実行する | `deletedCount: 0` が返る | |
