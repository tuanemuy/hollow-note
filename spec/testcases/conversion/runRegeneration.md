# テストケース: runRegeneration

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 本文があり元ファイルがある | 実行する | 直前の本文が `regeneration` の版として記録され、新しい本文に置き換わる | |
| 実行が失敗する | 実行する | 本文は変更されず、ジョブだけが `failed` になる | |
| Drive 上の元ファイルが削除されている | 実行する | `failed("targetMissing")` になり、本文は変わらない | |
| 追加指示を指定した | 実行する | 指示が構造化の要求に含まれる | |
| モデル指定がある | 実行する | 指定したモデルが使われる | |
| 既に `succeeded` のジョブ | 再度実行する | 何もせず終わる | |
| 実行後 | タグ・公開設定・共有リンクを確認する | いずれも維持されている | |
| 実行後 | 版の一覧を確認する | 直前の内容から「元に戻す」ことができる | |
| 連携が失効している | 実行する | `failed("providerAuthFailed")` になり、本文は変わらない | |
| 実行中 | そのノートを編集する | 編集は拒否される（実行中のジョブがあるため） | |
