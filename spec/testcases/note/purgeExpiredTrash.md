# テストケース: purgeExpiredTrash

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 削除から 31 日経過したノートがある | 実行する | そのノートが完全削除される | |
| 削除から 29 日経過したノートがある | 実行する | そのノートは残る | |
| `purgeAfter` のちょうど 1 ミリ秒前 | 実行する | 残る（境界値） | |
| 対象が `limit`（既定 100）を超える | 実行する | `limit` 件だけ削除され、残りは次の起動（10 分後）に持ち越される。継続要求は積まない | |
| `limit` の既定値 | 根拠を確認する | 1 件あたり約 3 クエリで、1 回の実行あたりのクエリ予算 500 から逆算した値である | |
| 1 件の削除が失敗する | 実行する | 記録して継続し、他の削除は成功する | |
| 対象が 0 件 | 実行する | `purgedCount: 0` が返る | |
| 実行後 | 使用量を確認する | 削除した分だけ減っている | |
