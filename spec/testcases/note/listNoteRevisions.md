# テストケース: listNoteRevisions

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 版が 5 件あるノート | 一覧する | 5 件が新しい順で返る | |
| 版が 25 件あるノート | 一覧する | 最新 20 件だけが返る | |
| 版が 0 件のノート | 一覧する | 空配列が返る | |
| viewer である | 一覧する | `NotFoundError("NOTE_NOT_FOUND")` が投げられる | |
| 版の作成者が削除済み | 一覧する | 表示名を解決できない旨を示して返る | |
| 20件の作成者が複数User shardへ分散する | 一覧する | `UserBatchReader`がIDをshard別batchへ分け、最大6接続で表示名を解決する | |
| 再生成による版がある | 一覧する | `reason: "regeneration"` が含まれる | |
| — | 一覧する | 各版に抜粋が含まれ、本文全体は含まれない | |
