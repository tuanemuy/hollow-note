# テストケース: countNotesByCreationDate

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 1 月と 3 月にノートがある | 引く | `availableMonths` に 1 月と 3 月だけが含まれる | |
| ある日に 3 件のノートがある | その月を指定して引く | その日の `count: 3` が返る | |
| ノートが 0 件 | 引く | `availableMonths` と `days` がどちらも空になる | |
| タイムゾーンが `Asia/Tokyo` で、UTC では前月末に作られたノート | 引く | 東京時間での月に数えられる | |
| 不正なタイムゾーン文字列 | 引く | `UTC` として扱われ、エラーにならない | |
| ワークスペースの viewer | 引く | 取得できる | |
| 非メンバー | 引く | `BusinessRuleError(InsufficientRole)` が投げられる | |
| ゴミ箱のノートがある | 引く | 集計に含まれない | |
