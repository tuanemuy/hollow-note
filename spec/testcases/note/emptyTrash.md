# テストケース: emptyTrash

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ゴミ箱に 10 件ある | 空にする | 10 件が完全削除され、`purgedCount: 10` が返る | |
| ゴミ箱が空 | 空にする | `purgedCount: 0` が返る | |
| ゴミ箱に 600 件ある | 空にする | 一括削除ジョブが登録され、登録件数が返る | |
| ワークスペースの viewer | 空にする | `BusinessRuleError(InsufficientRole)` が投げられる | |
| ワークスペースの editor | 空にする | 成功する | |
| 個人とワークスペースの両方にゴミ箱がある | 個人の文脈で空にする | ワークスペースのゴミ箱は残る | |
| 一部の削除が失敗する | 空にする | 他の削除は継続し、失敗件数が分かる | |
