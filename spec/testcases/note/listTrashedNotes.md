# テストケース: listTrashedNotes

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ゴミ箱に複数のノートがある | ゴミ箱を引く | 削除日時の新しい順に並ぶ | |
| ゴミ箱の各行 | 内容を確認する | `version` と `purgeAfter` を運ぶ（復元・完全削除の操作と残り日数の表示が要る） | |
| active なノートとゴミ箱のノートが混在する | ゴミ箱を引く | ゴミ箱のノートだけが返る | |
| ゴミ箱が空 | ゴミ箱を引く | 空のページと件数 0 が返る | |
| 別の利用者がゴミ箱にノートを持つ | 自分のゴミ箱を引く | 他人のゴミ箱には届かない | |
| 件数が 1 ページに収まらない | ページを指定して引く | ページごとに返しつつ、報告する件数はゴミ箱の総数である | |
| `limit` に上限を超える値を渡す | ゴミ箱を引く | 1 ページ 100 件に丸められる（境界値） | |
| `page` に 1 未満の値を渡す | ゴミ箱を引く | 先頭ページを返す | |
| ワークスペースの editor | そのワークスペースのゴミ箱を引く | ワークスペースのゴミ箱が返り、本人の個人ゴミ箱は混ざらない | |
| ワークスペースの viewer | そのワークスペースのゴミ箱を引く | `BusinessRuleError(InsufficientRole)` が投げられる（`viewTrash` を要求する） | |
| 非メンバー | そのワークスペースのゴミ箱を引く | `BusinessRuleError(InsufficientRole)` が投げられる | |
| 存在しないワークスペース | ゴミ箱を引く | `NotFoundError("WORKSPACE_NOT_FOUND")` が投げられる | |
