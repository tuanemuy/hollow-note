# テストケース: renameNote

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 編集権限のあるノート | タイトルを変更する | タイトルが更新され、由来が `manual` になり、`note.renamed` が発行される | |
| — | 空文字列にする | タイトルが `"無題"` になり、エラーにならない | |
| — | 空白のみにする | タイトルが `"無題"` になる | |
| — | 200 文字にする | 成功する（境界値） | |
| — | 201 文字にする | `BusinessRuleError(InvalidTitle)` が投げられる | |
| 由来が `auto` のノート | 変更する | 由来が `manual` に変わり、以降は変換結果で上書きされない | |
| viewer である | 変更する | `NotFoundError("NOTE_NOT_FOUND")` が投げられる | |
| 同じタイトルのノートが既にある | 同じタイトルにする | 成功する（重複を許す） | |
| 他者が先に更新した | 古い `expectedVersion` で変更する | `ConflictError("OPTIMISTIC_LOCK_FAILURE")` が投げられる | |
