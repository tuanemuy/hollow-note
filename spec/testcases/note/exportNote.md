# テストケース: exportNote

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 本文のある自分のノート | HTML でダウンロードする | スタイルと画像を埋め込んだ 1 ファイルが `kind: "immediate"` で即時に返り、`ticket` は `null` になる | |
| `styleMode: "preserve"` のノート | HTML でダウンロードする | 既定スタイルが埋め込まれない | |
| 埋め込めない外部参照がある | HTML でダウンロードする | その参照は元の URL のまま残り、他は埋め込まれる | |
| 本文のあるノート | Markdown でダウンロードする | HTML から変換された Markdown が即時に返る | |
| 表現できない要素を含む本文 | Markdown でダウンロードする | その部分は HTML のまま残る | |
| 期限内の生成物も実行中の `pdfExport` ジョブもない | PDF でダウンロードする | ジョブが登録され、`kind: "job"`・`jobId` と `{ kind: "job" }` の署名済み `ExportTicket` が返る | |
| 同じ版の PDF 生成物があり、残りの保持期間が十分にある（`expiresAt >= now + 35 分`。`runNoteExport` が作った 24 時間 TTL の artifact） | 同じノートを PDF でダウンロードする | ジョブを登録せず、`kind: "file"`・`fileId` と `{ kind: "file" }` のチケットが返る（再生成しない） | |
| 一括ダウンロードの子（`runBulkExportItem`）が作った 7 日 TTL の生成物が、同一ノート・同版で残り時間も十分にある | PDF でダウンロードする | 上限の条件はないため、経路によらず再利用され `kind: "file"` が返る（EX-01 の「24 時間保持」は保持期間の**下限**の約束であり、それより長く残る生成物を返しても約束に反しない） | |
| 同じ版の PDF 生成物はあるが、残りの保持期間がチケットの有効期間（30 分）を下回る（TTL 24 時間の artifact で生成から 23 時間 45 分が経過した、など） | PDF でダウンロードする | 再利用されず、新しいジョブが登録されて `kind: "job"` が返る（または実行中のジョブに相乗りする）。有効期間 30 分のチケットを返した直後に artifact のほうが先に失効し、ダウンロードが `ARTIFACT_EXPIRED` で落ちるのを防ぐため | |
| 同じ版の PDF 生成物の `expiresAt` がちょうど `now + 35 分` | PDF でダウンロードする | 下限は「以上」のため再利用され、`kind: "file"` が返る（境界値） | |
| 同じ版の PDF 生成物の `expiresAt` が `now + 35 分` をわずかに下回る | PDF でダウンロードする | 下限を満たさないため再利用されず、`kind: "job"` が返る（境界値） | |
| 生成物はあるが、その後の本文更新で版が変わった | PDF でダウンロードする | 同版でないため再利用されず、新しいジョブが登録されて `kind: "job"` が返る | |
| 他の利用者が作った同版の生成物が期限内にある | 別の閲覧者が PDF でダウンロードする | 要求者をまたぐ再利用は意図した挙動のため再利用される（artifact はノートの版だけから決まる純粋な生成物で、アクセスは要求のたびに再評価される） | |
| 同じノートの `pdfExport` ジョブが実行中 | 別の閲覧者が PDF でダウンロードする | 新規登録されず、その実行中ジョブへの `{ kind: "job" }` チケットが返る（相乗り） | |
| 匿名の閲覧者が公開ノートを PDF でダウンロードする | 登録されたジョブを確認する | `requestedBy: null`・`parentId: null` で登録され、`scope` はノートの所有文脈から導出される（匿名でも `scope` は対象ノートの所有文脈） | |
| サインイン済みの利用者が PDF でダウンロードする | 登録されたジョブを確認する | `requestedBy` が要求者になり、ジョブ履歴に現れる | |
| サインイン済みの利用者が、参加ワークスペース所有のノートを PDF でダウンロードする | 登録されたジョブの `scope` を確認する | `{ type: "workspace", workspaceId }` が入る（要求者からは導かない。生成物の帰属先が要求者の個人 subject であることとは別物） | |
| チケットが失効した | 同じノートを PDF でダウンロードし直す | 相乗りまたは生成物の再利用で新しいチケットが発行され、同じ結果に再到達できる | |
| 変換処理中のノート | ダウンロードする | `ValidationError("NOTE_CONTENT_NOT_READY")` が投げられる | |
| 「要 LLM 連携」のノート | ダウンロードする | `ValidationError("NOTE_CONTENT_NOT_READY")` が投げられる | |
| 公開ノート（未サインインの閲覧者） | ダウンロードする | 成功する | |
| 共有リンクの閲覧者（パスワード通過済み） | ダウンロードする | 成功する | |
| 共有リンクの閲覧者（パスワード未通過） | ダウンロードする | `ValidationError("SHARE_PASSWORD_REQUIRED")` が投げられる | |
| 他人の非公開ノート | ダウンロードする | `NotFoundError("NOTE_NOT_FOUND")` が投げられる | |
| タイトルに使えない文字を含む | ダウンロードする | ファイル名の該当文字が置き換えられる | |
| タイトルが記号のみで置換後に空になる | ダウンロードする | ファイル名にノート ID が使われる | |
| 閲覧者が短時間に大量に要求する | ダウンロードする | `ValidationError("RATE_LIMITED")` が投げられる（transport 層のレート制限） | |
