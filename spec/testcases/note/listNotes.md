# テストケース: listNotes

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 個人所有の active なノートが複数ある | 一覧を引く | active なノートだけがページで返り、総件数が添えられる | |
| 一覧の各行 | 版を確認する | その時点の `version` を運ぶ（行から起こす操作が期待版を要るため） | |
| ノートを 1 件も持たない利用者 | 一覧を引く | 空のページと件数 0 が返る | |
| ワークスペースのメンバー | そのワークスペースの一覧を引く | ワークスペース所有のノートだけが返り、本人の個人ノートは混ざらない | |
| 非メンバー | そのワークスペースの一覧を引く | `BusinessRuleError(InsufficientRole)` が投げられる | |
| 存在しないワークスペース | 一覧を引く | `NotFoundError("WORKSPACE_NOT_FOUND")` が投げられる | |
