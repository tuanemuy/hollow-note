# テストケース: restoreNote

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| ゴミ箱にある公開だったノート | 復元する | `lifecycle: "active"` になり、公開ステータスが復活する | |
| ゴミ箱にある限定公開だったノート | 復元する | 同じ共有リンクで再び到達できる | |
| ゴミ箱にあるノート | 復元する | タグの付与が復活する | |
| ゴミ箱にあるノート | 応答の `version` を確認する | 復元後の版が返り、そのまま次の編集の `expectedVersion` に使える | |
| ゴミ箱にないノート | 復元する | `ValidationError("NOTE_NOT_TRASHED")` が投げられる | |
| viewer である | 復元する | `NotFoundError("NOTE_NOT_FOUND")` が投げられる | |
| 復元後 | 一覧を開く | そのノートが現れる | |
| 所属ワークスペースが削除済み | 復元する | `NotFoundError("NOTE_NOT_FOUND")` が投げられる | |
