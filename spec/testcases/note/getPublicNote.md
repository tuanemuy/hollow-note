# テストケース: getPublicNote

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 公開ノート（個人所有） | 引く | 本文・著者のハンドルと表示名・メタ情報が返る | |
| 公開ノート（ワークスペース所有） | 引く | ワークスペースのスラッグと名前も返る | |
| 限定公開のノート | 引く | `NotFoundError("NOTE_NOT_FOUND")` が投げられる | |
| 非公開のノート | 引く | `NotFoundError("NOTE_NOT_FOUND")` が投げられる | |
| かつて公開されていて削除されたノート | 引く | `NotFoundError("NOTE_GONE")` が投げられる（インデックス削除を促す） | |
| ゴミ箱に入れられた公開ノート | 引く | `NotFoundError("NOTE_GONE")` が投げられる | |
| 存在しないノート ID | 引く | `NotFoundError("NOTE_NOT_FOUND")` が投げられる | |
| 著者がハンドルを変更した | 旧ハンドルの URL で引く | 「見つかりません」が返る | |
| 作成者が退会したワークスペース所有の公開ノート | 引く | ノート自体は公開のまま読め、著者は `{ displayName: "退会した利用者", handle: null }` として返り、著者ページへのリンクは出さない（R-59。AC-09 で退会時に消えるのは個人所有ノートのみ） | |
| 作成者の解決が `USER_NOT_FOUND` になる | 引く | 例外にせず同じフォールバック（「退会した利用者」・著者リンクなし）を用いる | |
| 退会した作成者のノート | 読み取りモデルの著者表示と比べる | `projectNoteChanges` / `rebuildNoteProjection` の既定値と同じ文言に揃っている | |
| — | 引く | `description` が抜粋から生成されている | |
| ワークスペースが非公開の公開ノート | 引く | ノート自体は取得できる | |
