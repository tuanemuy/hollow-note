# テストケース: searchNotes

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 個人ノートが 5 件ある | 条件なしで検索する | 5 件が更新日時の降順で返る | |
| ノートが 0 件 | 検索する | 空配列と `count: 0` が返る | |
| 本文に「設計」を含むノートがある | 「設計」で検索する | 該当ノートが返り、抜粋がハイライトされる | |
| 日本語の本文がある | 単語区切りのない語で部分一致検索する | 該当ノートが返る | |
| — | 1 文字で検索する | 検索語は無視され、全件が返る | |
| タグ A と B を持つノート、A のみのノートがある | A と B の両方で絞り込む | 両方を持つノートだけが返る | |
| 2 月作成のノートがある | 2 月で絞り込む（タイムゾーン指定あり） | 利用者のタイムゾーンで 2 月に入るノートだけが返る | |
| 条件に一致しない | 検索する | 空配列が返る | |
| ワークスペースの viewer | そのワークスペースを対象に検索する | 一覧が返る | |
| 非メンバー | そのワークスペースを対象に検索する | `BusinessRuleError(InsufficientRole)` が投げられる | |
| ワークスペースの viewer | `lifecycle: "trashed"` で検索する | `BusinessRuleError(InsufficientRole)` が投げられる | |
| 変換処理中のノートがある | 検索する | 一覧に含まれ、`contentStatus: "processing"` が返る | |
| `limit` を 101 にする | 検索する | `ValidationError("INVALID_PAGINATION")` が投げられる | |
| `limit` を 100 にする | 検索する | 成功する（境界値） | |
| 検索が長時間かかる | 検索する | `SystemError(TimeoutError)` が投げられる | |
| タイトル順を指定する | 検索する | 日本語を含むタイトルでも安定した順序で返る | |
