# テストケース: listPendingInvitations

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| owner で保留中の招待が 2 件ある | 一覧する | 2 件が返る | |
| 受諾済み・取り消し済みの招待がある | 一覧する | それらは含まれず、`count` は保留中の総数になる | |
| 終端状態の招待が 1 ページ分より多くある | 一覧する | 保留中の招待が隠れず、1 ページ目に返る | |
| 保留中の招待が 3 件あり 2 件目のページを引く | 一覧する | そのページの行数ではなく保留中の総数が `count` になる | |
| 期限切れの保留中の招待がある | 一覧する | 含まれ、`expired: true` になる | |
| editor である | 一覧する | `BusinessRuleError(InsufficientRole)` が投げられる | |
| 保留中の招待が 0 件 | 一覧する | 空配列と `count: 0` が返る | |
| — | 一覧する | 応答に招待トークンが含まれない | |
