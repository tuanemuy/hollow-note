# テストケース: listConnections

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 両方の連携がある | 一覧する | 2 件が状態・アカウント表示・最終利用日時つきで返る | |
| 連携が 1 つもない | 一覧する | 両方のプロバイダーが `status: "disconnected"` として返る | |
| 失効した連携がある | 一覧する | `status: "expired"` が返る | |
| — | 一覧する | 応答にアクセストークンやリフレッシュトークンが含まれない | |
| Drive の連携がある | 一覧する | `settings` にフォルダと自動バックアップの設定が含まれる | |
| OpenRouter の連携がある | 一覧する | `settings` にモデル設定が含まれる | |
| アカウント表示が取得できていない | 一覧する | `accountLabel: null` が返る | |
