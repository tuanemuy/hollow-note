# テストケース: listBackupStates

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 3 件のうち 2 件がバックアップ済み | まとめて引く | 2 件が `backedUp: true`、1 件が `false` になる | |
| バックアップ済みのノート | 引く | `webViewUrl` と `backedUpAt` が返る | |
| ノート ID を 1 件も渡さない | 引く | 空のマップが返る | |
| 存在しないノート ID を含む | 引く | `backedUp: false` として返り、エラーにならない | |
