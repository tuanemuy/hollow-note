# テストケース: listTagsWithUsage

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| タグが 5 件ある | 使用件数順で一覧する | 5 件が件数の降順で返る | |
| 使用件数 0 のタグがある | 一覧する | 含まれ、`usageCount: 0` になる | |
| タグが 0 件 | 一覧する | 空配列が返る | |
| キーワードを指定する | 一覧する | 名前に一致するタグだけが返る | |
| 最終使用日時順を指定する | 一覧する | 最後に付与された順で返る | |
| 一度も付与されていないタグ | 一覧する | `lastUsedAt: null` になる | |
| ワークスペースの viewer | 一覧する | 一覧が返り、`canManage: false` になる | |
| ワークスペースの editor | 一覧する | `canManage: true` になる | |
| 非メンバー | 一覧する | `BusinessRuleError(InsufficientRole)` が投げられる | |
| 個人スコープ | 一覧する | ワークスペースのタグは含まれない | |
