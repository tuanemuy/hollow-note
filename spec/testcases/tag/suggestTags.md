# テストケース: suggestTags

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| タグが 10 件ある | 空の `prefix` で候補を求める | 使用頻度の高い順に `limit` 件が返る | |
| 「設」で始まるタグが 2 件ある | 「設」で候補を求める | その 2 件が返る | |
| 一致するタグがない | 候補を求める | 空配列が返る | |
| 大文字で入力する | 候補を求める | 正規化されて一致する | |
| ワークスペースのスコープ | 候補を求める | 個人のタグは含まれない | |
| 非メンバー | 候補を求める | `BusinessRuleError(InsufficientRole)` が投げられる | |
