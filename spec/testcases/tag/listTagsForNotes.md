# テストケース: listTagsForNotes

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 3 件のノートにそれぞれタグが付いている | まとめて引く | ノート ID ごとにタグの配列が返る | |
| タグが付いていないノートを含む | 引く | そのノートは空配列になる | |
| ノート ID を 1 件も渡さない | 引く | 空のマップが返る | |
| 存在しないノート ID を含む | 引く | そのノートは空配列になり、エラーにならない | |
| 異なるスコープのノートを混ぜて渡す | 引く | それぞれのスコープのタグが返る | |
