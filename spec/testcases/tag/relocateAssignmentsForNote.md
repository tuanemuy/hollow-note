# テストケース: relocateAssignmentsForNote

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 移動先に同名のタグがある | 実行する | その付与が移動先のタグに付け替わる | |
| 移動先に同名のタグがない | 実行する | 付与が外れ、移動先にタグは新規作成されない | |
| 一部だけ同名タグがある | 実行する | 一致した分だけ付け替わり、残りは外れる | |
| 元の付与に `assignedBy` が記録されている | 実行する | 作り直された付与の `assignedBy` が元の付与の値を引き継ぐ（`note.moved` の payload に操作者は含まれないため、入力に `actorUserId` は取らない） | |
| タグが 1 件も付いていない | 実行する | 何も起きず成功する | |
| 同じイベントを 2 回受け取る | 2 回実行する | 2 回目は計画が空になり、結果が変わらない | |
| 対象ノートが既に削除済み | 実行する | 何もせず成功する | |
| 大文字小文字だけが違う同名タグが移動先にある | 実行する | 正規化して一致し、付け替わる | |
| 書き込みが失敗する | 実行する | `SystemError(DatabaseError)` が投げられ、再配送に委ねられる | |
