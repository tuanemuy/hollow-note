# テストケース: importExternalReferences

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 外部画像を 3 件参照する本文 | 実行する | 3 件が保管され、本文の参照先が差し替わる | |
| 404 を返す参照がある | 実行する | その参照は元の URL のまま残り、`failed` に記録される | |
| タイムアウトする参照がある | 実行する | 元の URL のまま残り、記録される | |
| 内部アドレスを指す参照がある | 実行する | 取得されず、記録される | |
| ループバックアドレスを指す参照がある | 実行する | 取得されず、記録される | |
| 既にサービス内のストレージを指す参照 | 実行する | 差し替えられず `skipped` に数えられる | |
| 参照が 201 件ある | 実行する | 200 件まで取り込まれ、以降は打ち切られる | |
| 合計 101 MB になる参照がある | 実行する | 上限に達した時点で打ち切られ、成功として返る | |
| 相対パスの参照がある | 実行する | 同時にアップロードされたファイル群から解決を試み、見つからなければ残る | |
| 本文が `ready` でない | 実行する | 何もせず返る | |
| 本文の保存が競合する | 実行する | 1 度読み直して再適用する | |
| 再適用しても競合する | 実行する | `ConflictError` が投げられる | |
| 同じジョブを 2 回実行する | 2 回実行する | 既に差し替え済みの参照は `skipped` になり、結果が変わらない | |
