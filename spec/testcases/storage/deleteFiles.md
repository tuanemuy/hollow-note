# テストケース: deleteFiles

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 3 件のファイルがある | まとめて削除する | メタデータが削除され、`storage.fileDeleted` が 3 件発行される | |
| 一部が既に削除済み | 削除する | 無視して継続し、残りが削除される | |
| 空の配列を渡す | 削除する | `deletedCount: 0` が返る | |
| 削除後 | 使用量を確認する | 保存容量が減っている | |
| 削除後 | オブジェクトストレージを確認する | 実体は `storage.fileDeleted` を購読する `deleteStoredObjects` が削除する（メタデータの削除と同一トランザクションにできないため後追いになる） | |
| 発行した `storage.fileDeleted` | payload を確認する | `objectKey` を含む（購読側がファイルの行を引き直さずに実体を消せるようにするため） | |
| 同じファイル ID を 2 回削除する | 2 回実行する | 二重に減算されない | |
