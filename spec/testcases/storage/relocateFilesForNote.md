# テストケース: relocateFilesForNote

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 元ファイルとメディア 2 件を持つノートが移動した | 実行する | 3 件の所有者が移動先になり、`storage.fileOwnerChanged` が 3 件発行される | |
| 実行後 | 使用量を確認する | 移動元の保存容量が減り、移動先が増えている | |
| 既に所有者が移動先と一致している | 実行する | 何もせず、イベントも発行されない | |
| 同じイベントを 2 回受け取る | 2 回実行する | 2 回目は何も起きず、容量が二重に移らない | |
| ノートが既に削除済み | 実行する | 何もせず成功する | |
| 一部のファイルが不在 | 実行する | 無視して継続する | |
| 版が競合する | 実行する | 読み直して再適用する | |
| ファイルを 1 件も持たないノート | 実行する | `relocatedCount: 0` が返る | |
