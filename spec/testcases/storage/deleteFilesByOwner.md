# テストケース: deleteFilesByOwner

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者が 120 件のファイルを持ち `batchSize: 50` | 実行する | 50 件ずつ処理され、すべて削除されるまで再登録される | |
| ワークスペースのファイルがある | ワークスペースを対象に実行する | そのワークスペースのファイルだけが削除される | |
| 対象が 0 件 | 実行する | `deletedCount: 0` が返る | |
| 1 件の削除が失敗する | 実行する | 記録して継続する | |
| 同じ要求を 2 回実行する | 2 回実行する | 結果が変わらない | |
| アイコンや生成物も所有している | 実行する | 用途によらずすべて削除される | |
