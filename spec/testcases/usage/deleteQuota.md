# テストケース: deleteQuota

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 利用者のクォータがある | 利用者を対象に実行する | クォータと LLM の記録が削除される | |
| ワークスペースのクォータがある | ワークスペースを対象に実行する | クォータが削除される（LLM の記録は利用者に紐づくため対象外） | |
| 既に削除済み | 実行する | 成功として返る | |
| 同じイベントを 2 回受け取る | 2 回実行する | 結果が変わらない | |
| 複数月の LLM 記録がある | 利用者を対象に実行する | すべての月の記録が削除される | |
