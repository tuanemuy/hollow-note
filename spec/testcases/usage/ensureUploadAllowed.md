# テストケース: ensureUploadAllowed

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 残量が十分 | 検査する | 例外を投げず通る | |
| 残量とちょうど同じサイズ | 検査する | 通る（境界値） | |
| 残量より 1 バイト大きい | 検査する | `BusinessRuleError(StorageQuotaExceeded)` が投げられる | |
| LLM 実行回数の残りが 1、`llmCalls: 1` | 検査する | 通る（境界値） | |
| LLM 実行回数の残りが 0、`llmCalls: 1` | 検査する | `BusinessRuleError(LlmQuotaExceeded)` が投げられる | |
| LLM の記録がなく `llmCalls: 1` | 検査する | 初期値で判定され、通る | |
| クォータのレコードがない | 検査する | 初期値で判定される | |
| `llmCalls: 0` で LLM の記録がない | 検査する | 通る | |
| ワークスペースを主体に指定する | 検査する | ワークスペースの上限で判定される | |
