# テストケース: signOutOtherSessions

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 同じ利用者に 3 件のセッションがある | 1 件を現在のセッションとして実行する | Userの`authEpoch`が1進み、現在の1行だけが新世代へ追随して`revocationAccepted: true`を返す。他の2件は物理削除前から無効 | |
| セッションが 1 件のみ | 実行する | 世代を進めて現在行を追随させ、`revocationAccepted: true`を返す | |
| 現在のセッションが期限切れ | 実行する | `ValidationError("UNAUTHENTICATED")` が投げられ、削除は起きない | |
| 他の利用者のセッションが存在する | 実行する | 他の利用者のセッションは削除されない | |
| 同じ利用者にセッションが10,000件ある | 実行する | Userと現在Sessionの2行のcommitで即時失効し、旧世代行は100件ずつ継続回収する | |
