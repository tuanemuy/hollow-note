# テストケース: signOutOtherSessions

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| 同じ利用者に 3 件のセッションがある | 1 件を現在のセッションとして実行する | 他の 2 件が削除され、`revokedCount: 2` が返る。現在のセッションは有効なまま | |
| セッションが 1 件のみ | 実行する | 削除は起きず `revokedCount: 0` が返る | |
| 現在のセッションが期限切れ | 実行する | `ValidationError("UNAUTHENTICATED")` が投げられ、削除は起きない | |
| 他の利用者のセッションが存在する | 実行する | 他の利用者のセッションは削除されない | |
