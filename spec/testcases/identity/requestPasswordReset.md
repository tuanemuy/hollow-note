# テストケース: requestPasswordReset

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| パスワード認証手段を持つ利用者がいる | 再設定を要求する | 既存の再設定トークンが削除され、新しいトークンで再設定メールが送られる | |
| Google のみで登録した利用者がいる | 再設定を要求する | `passwordResetUnavailable` の案内メールが送られ、再設定トークンは作られない | |
| `DeletingUser`のメールアドレス | 再設定を要求する | 未登録と同じ成功応答で、tokenもメールも発行しない | |
| 未登録のメールアドレス | 再設定を要求する | メールは送られず、成功として返る（存在を漏らさない） | |
| — | 形式が不正なメールアドレスで要求する | `BusinessRuleError(InvalidEmail)` が投げられる | |
| 同じメールアドレスへの要求が短時間に連続する | 要求する | レート制限がかかり、メールは送られず成功として返る | |
| 直近 59 秒以内に要求済み | 再設定を要求する | 新しいトークンは発行されず、成功として返る | |
| 直近 61 秒前に要求済み | 再設定を要求する | 新しい再設定メールが送られる（間隔制限の境界値） | |
| 既存の再設定トークンが未消費で残っている | 再度要求する | 古いトークンは無効になり、新しいトークンだけが有効になる | |
