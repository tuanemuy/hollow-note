# テストケース: listIdentities

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| パスワードと Google の 2 件を持つ利用者 | 一覧する | 2 件が返り、`removable: true` になる | |
| 認証手段が 1 件だけの利用者 | 一覧する | 1 件が返り、`removable: false` になる | |
| — | 一覧する | 応答にパスワードのハッシュやトークンが含まれない | |
| OAuth の認証手段がある | 一覧する | `provider` と `accountLabel` が含まれる | |
| パスワードの認証手段がある | 一覧する | `provider` が `null` になる | |
