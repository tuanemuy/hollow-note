# テストケース: resendVerificationEmail

| 前提条件 | 操作 | 期待結果 | 実装ステータス |
|---|---|---|---|
| `PendingUser` が存在する | 再送を要求する | 既存の確認トークンが削除され、新しいトークンで確認メールが送られる | |
| 直近 59 秒以内に再送済み | 再送を要求する | メールは送られず、成功として返る | |
| 直近 61 秒前に再送済み | 再送を要求する | 新しいメールが送られる（間隔制限の境界値） | |
| `ActiveUser` が存在する | 再送を要求する | メールは送られず、成功として返る | |
| 未登録のメールアドレス | 再送を要求する | メールは送られず、成功として返る（存在を漏らさない） | |
| — | 形式が不正なメールアドレスで要求する | `BusinessRuleError(InvalidEmail)` が投げられる | |
