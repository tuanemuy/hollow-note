# 外部連携 テスト

## 概要

このドキュメントは、OpenRouter（LLM）と Google Drive（バックアップ）の連携、およびバックアップからの再生成に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/integration.md`（IN-01〜IN-09）

## 前提条件

### 環境

- テスト用の OpenRouter アカウント（残高あり）を用意できる
- テスト用の Google アカウント（Drive の空き容量あり）を用意できる
- Drive の容量不足・権限失効を再現するための管理者操作ができる（できない場合は該当 TC を対象外とする）

### テストデータ

| 名前 | 内容 |
|---|---|
| ユーザー A | `user-a@example.com` / 連携なしの状態から始める |
| 画像ノート | JPEG をアップロードして作った「要 LLM 連携」状態のノート |
| Markdown ノート | 機械変換で本文が生成済みのノート |
| 手動作成ノート | エディタで新規作成し、元ファイルを持たないノート |

### 事前準備

1. ユーザー A でサインインする
2. `/settings/integrations` を開き、両方の連携が「未連携」であることを確認する

## カバレッジ

### ユースケースエラーケース対応表

| ユースケース | エラーケース | 対応TC | 備考 |
|---|---|---|---|
| startIntegrationOAuth | 未知のプロバイダー | 対象外 | UI からは既知のプロバイダーしか選べない |
