# 編集 テスト

## 概要

このドキュメントは、ノートの新規作成・本文の編集・削除・ゴミ箱に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/editing.md`（ED-01〜ED-11）

## 前提条件

### 環境

- ユーザー A（`user-a@example.com`）とユーザー B（`user-b@example.com`）でサインインできる
- 両者が editor として参加するワークスペース `設計チーム` がある
- ユーザー B のみが viewer として参加するワークスペース `閲覧のみ` がある
- 通信を一時的に遮断できる（ブラウザの開発者ツールのオフライン設定など）

### テストデータ

| 名前 | 内容 |
|---|---|
| 装飾ノート | `sample.html` から作った、`style` 要素と `class` 属性を持つノート |
| 素朴ノート | `sample.md` から作った、装飾のないノート |
| 空ノート | エディタで新規作成した本文が空のノート |
| 処理中ノート | 大きめのファイルをアップロードした直後の、変換処理中のノート |
| `over-800kb.html` | サニタイズ後に 800,000 バイトをわずかに超える HTML。段落を繰り返して作る |
| `just-under-800kb.html` | サニタイズ後に 800,000 バイトをわずかに下回る HTML |
| `unsafe-elements.html` | `<script>` / `<iframe>` / `<object>` / `<embed>` / `<form>` と入力欄 / `<base>` / `<meta http-equiv="refresh">` / `<link rel="stylesheet">` を 1 つずつ含む HTML |
| `unsafe-srcdoc.html` | `<iframe srcdoc="&lt;script&gt;alert(1)&lt;/script&gt;">` を含む HTML |
| `unsafe-css.html` | `<style>` に `position: fixed` の宣言と `@import url(...)` を、`style` 属性に `position: fixed` を含む HTML。いずれの箇所にも残ってよい宣言（`color` など）を併記する |
| `unsafe-url.html` | `javascript:` / `vbscript:` / `data:text/html` / `data:image/svg+xml` の URL と、残るはずの `data:image/png` の画像を含む HTML |
| `safe-rich.html` | 許可リストの内側の要素だけからなる HTML。入れ子の表・`<details>` / `<summary>` / `<figure>` / `<figcaption>` / ルビ（`<ruby>` / `<rt>`）と、`class` / `data-*` / `aria-*` 属性を含む |

### 事前準備

1. ユーザー A でサインインし、個人の文脈でノート一覧を開く
2. 上記のテストデータを用意する
3. `over-800kb.html` / `just-under-800kb.html` は、`<p>あ...</p>` の段落を必要な数だけ繰り返したファイルをスクリプトで生成する。実際のサイズは保存時のエラー有無で確認する
