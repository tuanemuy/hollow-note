# 書き出し テスト

## 概要

このドキュメントは、ノートのダウンロード（HTML / Markdown / PDF、個別・一括）に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/export.md`（EX-01〜EX-04）

## 前提条件

### 環境

- ユーザー A（`user-a@example.com`）でサインインできる
- ユーザー B が viewer として参加するワークスペース `設計チーム` がある
- ダウンロードしたファイルの内容を確認できる（テキストエディタ、PDF ビューアー）

### テストデータ

| 名前 | 内容 |
|---|---|
| 装飾ノート | `style` 要素と画像を含む、`styleMode: preserve` のノート |
| 素朴ノート | 見出し・リスト・表を含む、`styleMode: default` のノート |
| 表現困難ノート | Markdown で表現できない要素（`iframe` 相当のブロック）を含むノート |
| 処理中ノート | 変換処理中で本文がまだないノート |
| 記号タイトルノート | タイトルが `///` のみのノート |
| 公開ノート | 公開ステータスのノート |
| 共有ノート | パスワード保護された限定公開のノート |
