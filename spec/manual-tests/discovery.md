# 発見 テスト

## 概要

このドキュメントは、タイムラインと公開コンテンツの横断検索に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/discovery.md`（DS-01〜DS-06）

## 前提条件

### 環境

- ユーザー A（ハンドル `user-a`）、ユーザー B（ハンドル `user-b`）、ハンドル未設定のユーザー C でサインインできる
- 公開ワークスペース `公開チーム`（スラッグ `open-team`）と、非公開ワークスペース `内緒チーム` がある
- シークレットウィンドウでサインインしていない閲覧者として確認できる

### テストデータ

| 所有者 | タイトル | 公開ステータス | タグ |
|---|---|---|---|
| ユーザー A（個人） | 公開メモ A | 公開 | `設計` |
| ユーザー A（個人） | 非公開メモ A | 非公開 | `設計` |
| ユーザー A（個人） | 限定公開メモ A | 限定公開 | （なし） |
| ユーザー B（個人） | 公開メモ B | 公開 | `設計` |
| `公開チーム` | チーム公開ノート | 公開 | `議事録` |
| `公開チーム` | チーム非公開ノート | 非公開 | `議事録` |
| `内緒チーム` | 内緒の公開ノート | 公開 | `設計` |

すべての公開ノートの本文に `共通キーワード` を含める。`公開メモ A` の本文には `東京` を、`公開メモ B` の本文には `東京都` を含める。

## TC-06: 公開検索でタグと期間を絞り込む

**種別**: 正常系
**目的**: DS-05 の絞り込みを検証する

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | 公開検索でタグ `設計` を選ぶ | `設計` が付いた公開ノートだけが返る |
| 2 | 所属先の異なる同名タグを確認する | 個人・ワークスペースをまたいで名前で一致し、両方が返る |
| 3 | 期間で絞り込む | 指定期間に**更新**されたノートだけが返る（作成日時ではなく更新日時が基準。結果に出る日時と同じ列で絞られる） |
| 4 | 終了日に指定した日に更新されたノートを確認する | 結果に含まれる（終了日は指定日を含む） |
| 5 | 開始日より前に作成され、期間内に更新されたノートを確認する | 結果に含まれる |
| 6 | 期間内に作成されたが期間外に更新されたノートを確認する | 結果に含まれない |
| 7 | 開始日だけ、終了日だけを指定する | それぞれ「その日以降」「その日以前」に更新されたノートが返る |
| 8 | キーワードもタグも指定せず期間だけで検索する | 検索語が短すぎる扱いにはならず、期間に該当する公開ノートが返る |

**確認ポイント**: 境界は UTC で解決される（サインイン不要の経路のため閲覧者のタイムゾーンを使わない）。ローカル時刻との差で 1 日ずれて見える場合はこの規約どおりであることを確認する
