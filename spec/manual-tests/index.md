## 実行の前に

1. `spec/scenario/` と `spec/pages/` を一読し、用語と画面名を把握する
2. 各テストドキュメントの「前提条件」に従って環境とテストデータを用意する
3. 複数の利用者を使うテストがあるため、ブラウザのプロファイルまたはシークレットウィンドウを 3 つ用意する
4. 「対象外」と注記された TC は、環境の制約で実行できない場合にのみ飛ばす。飛ばしたことを実行記録に残す

## 推奨する実行順序

前のカテゴリーで作ったデータを後のカテゴリーで使うため、次の順で実行すると準備の手間が少ない。

1. アカウント — 利用者を用意する
2. ワークスペース — 共同作業の場とメンバーを用意する
3. 外部連携 — OpenRouter と Google Drive をつなぐ
4. 取り込み — ノートを作る
5. 編集 — ノートの内容を整える
6. 整理 — タグと一覧の操作を確認する
7. 共有 — 公開範囲を設定する
8. 発見 — 公開されたものを外から確認する
9. 書き出し — ダウンロードを確認する
10. 処理 — ここまでで溜まったジョブの履歴を使って確認する
