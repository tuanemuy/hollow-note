# 取り込み テスト

## 概要

このドキュメントは、ファイルのアップロードと HTML への変換に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/import.md`（IM-01〜IM-06）

## 前提条件

### 環境

- ユーザー A（`user-a@example.com`）でサインインできる
- OpenRouter を連携済みの状態と未連携の状態を切り替えられる
- ユーザー A が editor として参加するワークスペース `設計チーム` と、viewer として参加するワークスペース `閲覧のみ` がある

### テストデータ

| ファイル名 | 内容 | 用途 |
|---|---|---|
| `sample.html` | `style` 要素を含む装飾済み HTML | 装飾の保持を確認する |
| `plain.html` | 装飾のない素朴な HTML | 既定スタイルの適用を確認する |
| `sample.md` | 見出しとリストを含む Markdown | 機械変換を確認する |
| `sample.docx` | 見出しと段落を含む Word 文書 | テキスト抽出と構造化を確認する |
| `text-pdf.pdf` | テキスト層のある PDF | 機械抽出を確認する |
| `scan-pdf.pdf` | テキスト層のないスキャン PDF | LLM 解析を確認する |
| `locked.pdf` | パスワード保護された PDF | 異常系 |
| `photo.jpg` | 文字が写った画像 | LLM でのテキスト抽出を確認する |
| `voice.m4a` | 1 分程度の音声 | 音声認識を確認する |
| `broken.docx` | 途中で切れた壊れたファイル | 異常系 |
| `archive.zip` | ZIP ファイル | 未対応形式 |
| `big-audio.m4a` | 201 MB の音声 | 境界値 |
| `edge-audio.m4a` | 200 MB ちょうどの音声 | 境界値 |
| `ref.html` | 外部の画像 URL を 3 件参照する HTML | 参照リソースの取り込みを確認する |
| `ref-201.html` | 外部の画像 URL を 201 件参照する HTML | 参照の件数上限を確認する |
| `edge-pdf.pdf` | 50 MB ちょうどの PDF | 境界値 |
| `over-pdf.pdf` | 51 MB の PDF | 境界値 |
| `bulk-100/` | 対応形式のファイル 100 件を含むフォルダ | 件数の境界値 |
| `bulk-101/` | 対応形式のファイル 101 件を含むフォルダ | 件数の境界値 |
| `bulk-501mb/` | 合計 501 MB になるファイル群 | 合計サイズの境界値 |

### 事前準備

1. ユーザー A でサインインし、個人の文脈でノート一覧を開く
2. 各テストの前に、OpenRouter の連携状態を指定された状態に揃える
3. 上限に達した状態を作るテスト（TC-24 / TC-25）のために、テスト環境の上限値を一時的に小さくしておく
   - 保存容量の上限を 10 MB に、当月の LLM 実行回数の上限を 2 回に設定する
   - 設定できない環境では、上限まで実データを作るか、これらの TC を対象外とする
4. サイズの大きいテストデータは、必要な大きさになるまで内容を繰り返したファイルをスクリプトで生成する
