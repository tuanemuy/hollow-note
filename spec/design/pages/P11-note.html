Attention Is All You Need — 読書メモ

Transformer の原論文を読み直しながら、Multi-Head Attention の直感的な理解をまとめた。PDF から取り込んだ図はオブジェクトストレージに保存済みで、配布元が消えても表示は変わらない。

1. 何を解いた論文か

再帰も畳み込みも使わず、注意機構だけで系列変換を組み立てられることを示した。学習の並列化が効くので、同じ計算資源でより大きなモデルを回せる。

We propose a new simple network architecture, the Transformer, based solely on attention mechanisms, dispensing with recurrence and convolutions entirely.

2. Multi-Head Attention

単一の注意で全部を担わせるのではなく、射影を分けて複数の「見方」を同時に走らせる。d_model = 512 を 8 ヘッドに割ると、1 ヘッドあたり 64 次元になる。

# scaled dot-product attention
def attention(q, k, v, mask=None):
    scores = q @ k.transpose(-2, -1) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    return softmax(scores, dim=-1) @ v

3. 位置エンコーディング

系列の順序情報を持たない構造なので、正弦波で位置を埋め込む。学習可能な埋め込みでも性能はほぼ変わらないと付録に書かれている。

  • 偶数次元は sin、奇数次元は cos
  • 波長は 2π から 10000·2π の等比数列
  • 学習時より長い系列にも外挿できることを狙った設計

読み直しで気づいたこと

  • Encoder / Decoder の非対称性を図に描き起こす
  • Label Smoothing の効き方を実験で確かめる
