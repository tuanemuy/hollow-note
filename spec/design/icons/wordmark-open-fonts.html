Hollow — Wordmark 候補（案B）

Vesica mark は据え置き。Wordmark を Avenir Next（Apple プロプラ・配布/埋め込み不可） から 埋め込み可能なオープン幾何学サンセリフへ置換する案の比較。狙いは OG 画像のフォント焼き込みを再現可能・ライセンス安全にすること。

現状の og-image.png は ImageMagick→librsvg→fontconfig 経由でラスタライズされ、fontconfig が macOS の Avenir Next を解決できず汎用 sans の Bold にフォールバックしている（SVG は font-weight 400 指定なのに実物は極太）。案 B はこれを解消する。
下記候補はいずれも SIL Open Font License。採用したら Web フォント（self-host）として同梱し、OG はその実フォントで焼き込む（or グリフをアウトライン化）。
weight は据え置き（Outfit / Poppins / DM Sans / Lexend / Sora = 300、他 = 400）。見た目を現行 Avenir に寄せる調整はトラッキング側で実施（素のサイドベアリングが各フォントで違うため一律にはせず、Avenir のリズムへ寄せた値を .f-* クラスに付与）。各カードに weight / tracking を表示。
※ このページは Google Fonts から候補を読み込み。最上段の「参照」だけは macOS の本物 Avenir Next を呼ぶので、Mac で開くと目標形と各候補を直接比較できる。
