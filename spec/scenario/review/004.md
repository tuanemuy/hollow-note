# シナリオレビュー 004

対象: `spec/scenario/` 配下すべて

## 1. 招待からのサインアップがメール確認と噛み合わない

WS-04 は「サインインしていない場合はサインイン / サインアップを求められ、完了後に招待の確認へ戻る」としている。一方 AC-02 / AC-04 では、メール確認が済むまでセッションを発行しない。招待された利用者が新規サインアップすると、招待リンクを開いたにもかかわらず確認メールの受信を待たされ、その後に招待リンクへ戻る必要がある。招待メールが届いている時点でそのアドレスの到達性は確認済みであり、二重の確認は無駄な迂回になる。

**対応**: 招待リンク経由でそのメールアドレスのままサインアップした場合は、確認済みとして扱いそのままセッションを発行する。招待と異なるメールアドレスでサインアップした場合は通常どおり確認を求める。WS-04 と AC-01 の双方に明記する。
