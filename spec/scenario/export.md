# 書き出し（EX）

ノートを HTML / Markdown / PDF でダウンロードするシナリオ。

## EX-01: ノートを 1 件ダウンロードする

**利用者**: 所有者 / メンバー
**事前条件**: 対象ノートを閲覧できる

### 基本フロー

1. ノート詳細のメニューから「ダウンロード」を選ぶ
2. 形式（HTML / Markdown / PDF）を選ぶ
3. HTML と Markdown は即座に生成されてダウンロードが始まる
4. PDF は生成に時間がかかるため、進捗を表示したうえで完了後にダウンロードが始まる

### 異常系・エッジケース

- HTML はスタイルと画像を埋め込んだ 1 ファイルとして出力する。埋め込めなかった参照は元の URL のまま残す
- Markdown は HTML から機械的に変換する。表現できない要素は HTML のまま残す
- PDF の生成に失敗した場合、理由と再試行の導線を表示する
- 本文が空（変換処理中 / 要 LLM 連携）のノートはダウンロードできない
- ファイル名はタイトルから生成し、使えない文字は置き換える。空になる場合はノートの識別子を使う
- 生成した PDF は一定期間（24 時間）保持し、その間は再生成せずに再ダウンロードできる

## EX-02: 複数のノートを一括ダウンロードする

**利用者**: 所有者 / メンバー
**事前条件**: 対象ノートを閲覧できる

### 基本フロー

1. 一覧で複数のノートを選び、操作バーから「ダウンロード」を選ぶ（OR-09）
2. 形式を選び、実行する
3. ZIP を生成するジョブが登録され、進捗が表示される
4. 完了すると通知が表示され、ダウンロードできる

### 異常系・エッジケース

- 件数の上限（500 件）または合計サイズの上限（1 GB）を超える場合、分割を促す
- ダウンロードできないノート（本文が空）は対象から除外し、件数を示す
- 一部のノートの生成に失敗した場合、成功分を含む ZIP を提供し、失敗した対象の一覧を同梱する
- ファイル名が重複する場合は連番を付けて衝突を避ける
- 絞り込み結果全体を対象とする「全選択」でも同じ上限が適用される
- 実行中に対象ノートが削除された場合、そのノートは除外して継続する

## EX-03: 一括ダウンロードの生成状況を確認して受け取る

**利用者**: 一括ダウンロードを実行した利用者
**事前条件**: EX-02 を実行している

### 基本フロー

1. 画面を離れても生成は継続し、処理ティッカーに進行中として表示される
2. 処理履歴（JB-01）から状況を確認できる
3. 完了すると通知が表示され、履歴からダウンロードできる
4. 生成物は一定期間（7 日）保持され、その間は何度でもダウンロードできる

### 異常系・エッジケース

- 生成に失敗した場合、理由と再実行の導線を示す
- 保持期間を過ぎた生成物は削除され、履歴には期限切れとして表示される
- 生成中にキャンセルできる。キャンセルすると中間生成物は破棄される
- 同時に実行できる一括ダウンロードは 1 件までとし、実行中は新たな要求を受け付けない。既に実行中である旨を示し、完了後に再実行するよう案内する（待機列は設けない）

## EX-04: 閲覧者がノートをダウンロードする

**利用者**: 閲覧者（サインイン不要）
**事前条件**: 公開ノート、または有効な共有リンク（必要ならパスワード通過済み）

### 基本フロー

1. 公開ページまたは共有リンクの画面で「ダウンロード」を選ぶ
2. 形式（HTML / Markdown / PDF）を選ぶ
3. EX-01 と同じ手順でダウンロードされる

### 異常系・エッジケース

- 閲覧できるノートは常にダウンロードできる（閲覧のみを許す設定は設けない）
- ダウンロード操作にレート制限をかける
- サインインしていない閲覧者の PDF 生成は、ダウンロード操作をした画面内の進捗表示で完結する。進捗の確認と受け取りには、操作時に発行される有効期限（短時間）つきの署名されたチケットを使い、処理履歴（JB-01）には現れない
- 進捗の確認とダウンロードのたびに閲覧の可否を確認し直す。閲覧中にノートが非公開に戻された・削除された・共有リンクが再発行された場合、「見つかりません」で失敗する
- チケットの有効期限が切れた場合や生成に失敗した場合の再試行は、ダウンロード操作のやり直しで行う（生成済みの PDF が保持期間内に残っていれば、生成し直さずにそれを受け取れる）
- 同じノートの PDF 生成が既に実行中の場合、新たな生成は始めず、実行中の生成の完了を待って同じ結果を受け取る
- 一括ダウンロードは閲覧者には提供しない
