# シナリオ一覧

利用者の視点から、本システムが提供する操作を列挙する。詳細はカテゴリーごとのファイルに記述する。

## 登場する利用者

| 呼称 | 説明 |
| --- | --- |
| 所有者 | ノートを所有する利用者。個人所有のノートの作成者、またはワークスペース所有ノートに対する owner / editor |
| メンバー | ワークスペースに参加している利用者（owner / editor / viewer） |
| 閲覧者 | 共有リンクや公開ページ経由でノートを見る利用者。ログインしていない場合を含む |

## シナリオ

### アカウント（AC）

| ID | シナリオ |
| --- | --- |
| AC-01 | メールアドレスとパスワードでアカウントを作成する |
| AC-02 | メールアドレスを確認する |
| AC-03 | Google アカウントでサインアップ / サインインする |
| AC-04 | メールアドレスとパスワードでサインインする |
| AC-05 | パスワードを再設定する |
| AC-06 | ログイン方法を追加・変更・解除する |
| AC-07 | プロフィールと公開ハンドルを編集する |
| AC-08 | サインアウトする |
| AC-09 | アカウントを削除する |
| AC-10 | 使用量を確認する |
