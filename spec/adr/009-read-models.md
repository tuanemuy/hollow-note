# 009. 一覧・検索・タイムラインは専用の読み取りモデルに投影する

## ステータス

承認済み

## コンテキスト

ノート一覧（P-10）は、1 回の問い合わせで次をすべて満たす必要がある。

- 現在の文脈（個人 / ワークスペース）による絞り込み
- 全文検索（タイトルと本文、日本語の部分一致）
- タグによる AND 絞り込み
- 作成月による絞り込み
- 更新日時 / 作成日時 / タイトル / 関連度による並べ替えとページング

一方でタグは Tag ドメインが持ち、Note は Tag を知らない（[ADR 008](./008-domain-boundaries.md)）。著者名やワークスペース名は Identity / Workspace が持つ。集約の境界を守ったまま素直に実装すると「タグから NoteId の集合を引き、その集合を Note の検索条件に渡す」形になり、条件に一致するノートが多いほど ID の受け渡しが膨らみ、関連度順の並べ替えとページングが成立しなくなる。

公開検索（DS-05）はさらに広く、全利用者・全ワークスペースの公開ノートを横断する。

## 決定

- 一覧・検索・タイムライン・公開検索・サイトマップの読み取りは、書き込みモデルではなく専用の読み取りモデル `note_search` に対して行う
- `note_search` は 1 ノート 1 行。本文から抽出したテキスト、タグ名の連結、著者の表示名とハンドル、ワークスペース名とスラッグを非正規化して持つ
- 全文検索は SQLite の FTS5 仮想テーブルを `note_search` に対応づけて構成する
- 更新はドメインイベントを購読するプロジェクションが行う。Note / Tag / Identity / Workspace のイベントがそれぞれ該当列を更新する
- 書き込み側（`NoteRepository`）は読み取りモデルを一切参照しない。読み取り側（`NoteQueryService`）は書き込みモデルを一切参照しない
- 投影は結果整合とする。アウトボックス経由の配送は少なくとも 1 回であり順序保証がないため、プロジェクションは冪等な上書きとして実装する
- 投影の遅延が許されない読み取り（ノート詳細、共有リンクの解決、権限判定）は書き込みモデルから直接読む

## 検討した代替案

### タグから NoteId の集合を引いて Note の検索条件に渡す

ドメイン境界はもっとも素直に守れるが、上に述べたとおり件数が増えると成立しない。ページングと関連度順が特に破綻する。不採用。

### Note の集約にタグを含める

読み取りは 1 テーブルで済むが、タグのリネーム・統合・削除が全ノートの更新になる（[ADR 008](./008-domain-boundaries.md) で検討済み）。不採用。

### 読み取りのときだけ JOIN を許し、境界を読み取りに限って緩める

実装は単純で投影の遅延もない。しかし「どこまで JOIN してよいか」の線引きが実装者ごとにぶれ、書き込みモデルのスキーマ変更が読み取り側を壊す。境界を守るなら明示的な読み取りモデルのほうが規律が保てる。不採用。

### 検索だけを外部の検索サービスに委ねる

運用は楽になるが、Cloudflare 上で完結させる前提から外れ、依存とコストが増える。D1 の FTS5 で要件を満たせる規模と判断した。不採用。

## 影響

- `note_search` テーブルと、それに対応する FTS5 仮想テーブルが必要になる
- プロジェクションを担うイベントハンドラーが必要になる。購読するイベントは Note の全イベント、`tag.assigned` / `tag.unassigned` / `tag.renamed` / `tag.merged` / `tag.deleted`、`identity.user.handleChanged` とプロフィール更新、`workspace.slugChanged` / `workspace.published` / `workspace.unpublished` / `workspace.created`（名前）
- 一覧に表示される内容は最大で数秒遅れうる。利用者の自身の操作については、操作元の画面が楽観的更新で即時反映するため体感上の遅延は生じない
- 投影が失われた場合に備え、書き込みモデルから全件を再投影するバッチが必要になる
- 読み取りモデルにはアクセス制御に使える情報（`visibility`、`owner`、`lifecycle`）を含める。公開検索は `visibility = 'public'` かつ `lifecycle = 'active'` の行のみを対象とする
