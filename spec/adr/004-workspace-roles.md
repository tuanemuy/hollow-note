# 004. ワークスペースのロールは owner / editor / viewer の 3 段階とする

## ステータス

承認済み

## コンテキスト

idea.md には「ワークスペースを作成したり参加したりできる」とあるのみで、参加者が何をできるかは未定義だった。ワークスペースは公開設定を持ち、公開すると公開ノートが外部に見える。誰がその設定を変えられるかを決めないと、公開範囲の管理ができない。

## 決定

ロールは 3 段階とする。

| 操作 | owner | editor | viewer |
| --- | --- | --- | --- |
| ノートの閲覧・ダウンロード | ○ | ○ | ○ |
| ノートの作成・アップロード | ○ | ○ | × |
| ノートの編集・削除・公開設定 | ○ | ○ | × |
| ノートの他所属への移動 | ○ | ○ | × |
| 元ファイルの Drive バックアップ | ○ | ○ | × |
| メンバーの招待・ロール変更・除名 | ○ | × | × |
| ワークスペース設定・公開設定の変更 | ○ | × | × |
| ワークスペースの削除 | ○ | × | × |

- owner は 1 ワークスペースに複数人置ける。最後の 1 人は自身のロール降格・脱退ができない
- ノートの編集権限はロールで決まり、作成者かどうかでは変わらない（共同編集を前提とするため）
- 元ファイルの Drive バックアップは、内容を自分の Drive に写すだけに見えるが「閲覧・ダウンロード」ではなく編集側に置く。バックアップ記録（`BackupRecord`）はノートに紐づく共有状態で、既存記録が別のメンバーのものなら所有者ごと付け替わり、その記録が再生成時にどのメンバーの Drive から元ファイルを取るかを決めるため（[usecases/integration.md](../usecases/integration.md) の `requestBackup` / `runBackup`）。PDF ダウンロードや一括ダウンロードは要求者個人に帰属する生成物を作るだけでノート側に何も書かないため、viewer に許す

## 検討した代替案

### owner / member の 2 段階

最小で分かりやすいが、「外部の人にワークスペースのノートを見せたいだけ」という要件を満たせない。閲覧専用の参加者を作れないと、限定公開リンクを個別に配る運用に逃げることになり、ワークスペースの意味が薄れる。不採用。

### owner / admin / editor / viewer の 4 段階

大きなチームでメンバー管理を委譲できる利点があるが、owner を複数人置ける設計にすれば admin の役割はほぼ owner で代替できる。段階が増えるほど権限表の説明コストと実装の分岐が増える。不採用。

## 影響

- 権限判定はワークスペース ID と利用者 ID からロールを引き、操作ごとの必要ロールと比較する形に統一できる
- メンバー管理画面ではロールの変更と除名を owner のみに出す。最後の owner に対する降格・脱退操作は UI 上も抑止する
- 招待時にロールを選択する必要がある
- ワークスペースの公開ページ（外部向け）には公開ノートのみを出す。ロールとは独立した判定になる
- editor → viewer の降格は、その利用者が要求した実行中ジョブのうち viewer では実行できない `kind`（取り込み・再生成・参照リソースの取り込み・Drive バックアップと一括操作系）の取り消しを伴う。本文や共有状態を書き換える実行体（`runConversion` / `runRegeneration` / `runBackup`）は実行時にロールを再確認しないため、この表の対応を実行中のジョブにも及ぼさないと降格後も本文やバックアップ記録が書き換わる（[usecases/workspace.md](../usecases/workspace.md) の `changeMemberRole`）。一括操作・一括ダウンロードの子は対象ノートが 1 件に定まっているぶん実行の直前に権限を確かめられるため、取り消しとは別に実行時にも再確認し、失っていれば `permissionRevoked` として失敗させる（[usecases/note.md](../usecases/note.md) の `runBulkNoteOperationItem` / `runBulkExportItem` の手順 2）。owner → editor の降格では、owner だけに許される操作に対応するジョブ種別が存在しないため取り消しは起きない
