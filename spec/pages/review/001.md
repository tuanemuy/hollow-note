# ページレビュー 001

対象: `spec/pages/index.md`

## 1. タグ管理の画面がない

OR-08（タグのリネーム・削除・統合）に対応する画面がどこにもない。P-10 のタグ絞り込みは選択のためのもので、使用件数の一覧・リネーム・統合・未使用タグの一括削除は行えない。文脈（個人 / ワークスペース）ごとに存在する必要があり、権限（ワークスペースでは owner / editor のみ）も持つ。

**対応**: タグ管理画面を追加し、URL を割り当てる。

## 2. ノートの新規作成に対応する画面と URL がない

ED-01 は「白紙のノートを新規作成する」で、WYSIWYG エディタが開き、入力すると非公開のノートが作成される。P-12（ノート編集）は既存ノートの編集として記述されており、`/notes/:noteId/edit` しか URL がない。ノートが作られる前にエディタを開く経路が定義されていない。

**対応**: P-12 に新規作成の入口（`/notes/new`）と、初回保存でノートが作られる状態を追加する。

## 3. 公開タイムラインの担当画面が P-10 と P-42 / P-43 で重複している

P-10 の機能に「作業用一覧と公開タイムラインの切り替え（DS-01, DS-02）」とあるが、公開タイムラインの実体は P-42（利用者の公開ページ）と P-43（ワークスペースの公開ページ）である。同じ内容を 2 か所で担当することになり、どちらを実装すべきか判別できない。DS-01 / DS-02 のシナリオでも、公開ページへ遷移して外部向け表示のバナーを見る流れになっている。

**対応**: P-10 からは公開タイムラインの担当を外し、公開ページへ遷移する導線のみを持たせる。対応シナリオの割り当ても整理する。

## 4. P-11 のダウンロードに関する状態が欠けている

P-11 の機能にダウンロードがあり、EX-01 では PDF の生成に時間がかかり進捗を表示するとしている。しかし P-11 の状態一覧には形式選択と PDF 生成中の状態がない。P-44 には「ダウンロード生成中（PDF）」があり、片側だけの記述になっている。

**対応**: P-11 の状態に形式選択・生成中・生成失敗・ダウンロード不可（本文が空）を追加する。

## 5. ワークスペース設定の URL が明示されていない

P-31〜P-34 はワークスペース設定の画面だが、URL 一覧には `/workspaces/:workspaceId/...` という包括的な記述しかなく、設定画面の経路が読み取れない。P-20（設定シェル）のナビゲーションに「ワークスペース」があることと合わせて、個人設定とワークスペース設定の関係が曖昧。

**対応**: URL 一覧にワークスペース設定の経路を明示し、P-20 との関係を記述する。
