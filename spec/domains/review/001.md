# ドメインレビュー 001

対象: `spec/domains/` 配下すべて

## 1. `ConversionFailureReason` の所属が依存方向と矛盾する

`ConversionFailureReason` は `note.md` の値オブジェクトとして定義されているが、`conversion.md` の `ConversionOutcome` と `job.md` の `JobFailure` がこれを参照している。依存方向の表では Conversion は Storage のみ、Job は Identity のみに依存すると宣言しており、実際の参照と食い違う。

**対応**:

- `ConversionFailureReason` を Conversion ドメインの値オブジェクトとして定義し、Note はそれを参照する（Note → Conversion を依存に追加）
- `JobFailure.reason` は Job 自身の `JobFailureReason` のみを取る（`ConversionFailureReason` の全値を包含しているため、Job から Conversion への依存は不要）

## 2. 依存方向の表が実際の型参照と一致していない

各ドメインファイルが参照している型を追うと、`domains/index.md` の表に載っていない依存が複数ある。

| ドメイン | 表に載っていない実際の依存 | 参照している型 |
| --- | --- | --- |
| Note | Conversion | `ConversionFailureReason` |
| Integration | Note, Storage | `NoteId`, `StoredFileId`, `Checksum`, `FileName`, `MimeType`, `ByteSize` |
| Job | Note, Storage, Workspace | `NoteId`, `StoredFileId`, `WorkspaceId` |
| Usage | Note, Storage | `NoteOwner`, `StorageOwner` |

いずれも循環は生まないが、表が実装の指針にならない。

**対応**: 表を実際の参照に合わせて更新し、循環がないことを明記する。

## 3. `HtmlProcessor.editTextNodes` の `path` が未定義

`TextNodeEdit = { path: string; text: string }` の `path` が何を指すのかが書かれていない。ビジュアルエディタ（ED-02）はこのポートだけを頼りに実装されるため、位置の表現方法が決まらないと実装できない。

**対応**: テキストノードの位置表現を明示し、位置がずれた場合の扱いも定める。

## 4. `NoteAccessPolicy.evaluate` のゴミ箱判定が循環した書き方になっている

判定順の 1 で「所有者側（下の 2 で `granted` になる立場）のみ `granted`」と、後続のステップを参照して自身を定義している。実装者はどちらを先に評価すべきか判断できない。

**対応**: 所有関係の判定を先に行い、ゴミ箱の扱いはその結果に対する後段の絞り込みとして書き直す。

## 5. `ExternalFetchPolicy.budget` の戻り値型が未定義

`budget(): FetchBudget` の `FetchBudget` にフィールドの定義がない。本文中に「1 ノートあたり最大 200 件・合計 100 MB」と書かれているが、型として表現されていない。

**対応**: `FetchBudget` のフィールドを定義する。

## 6. `NoteHtml` の空文字列を作る経路がない

`NoteHtml` は「生成経路は `HtmlProcessor.process` の結果のみ」としているが、`Note.createBlank` は「本文は空の `ready`（`html` は `""`）」で生成するとしている。空の HTML を作る手段が定義されていない。

**対応**: `NoteHtml.empty()` を生成経路として明記する。

## 7. `domains/index.md` のユースケース数が各ドメインの列挙と一致しない

index の表は Identity 15 / Note 19 / Tag 7 / Storage 4 / Integration 9 / Job 4 / Usage 2 としているが、各ドメインファイルの「ユースケース（概要）」に並ぶ数はそれぞれ 17 / 23 / 9 / 7 / 10 / 6 / 4 で食い違う。

**対応**: index の表を各ドメインファイルの列挙に合わせる。
