# TC-2: サインアップの項目エラーと送信抑止

**結果**: PASS
**対応する受け入れ基準**: AC-16（P-01）、AC-2（PlainPassword 8–128 + 英数）

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|---------|-----------|------|
| 1 | `/signup` のメール欄に `foo@` を入力 | 項目エラーが表示される | 「メールアドレスの形式が正しくありません」を表示。送信ボタンは `disabled` | PASS |
| 2 | パスワード欄に 7 文字 `Pass123` を入力 | 項目エラーが表示される | 「パスワードが短すぎます。8 文字以上で入力してください」を表示（強度メーターは「普通」） | PASS |
| 3 | パスワード欄に数字のみ `12345678` を入力 | 項目エラーが表示される | 「英字と数字の両方を含めてください」を表示（強度メーターは「弱い」） | PASS |
| 4 | 規約同意のチェックを外したまま送信を試みる | 送信が抑止される | 全項目を妥当な値（`user-c@example.com` / `Passw0rd123` / `User C`）にしても、同意チェックが外れている間は送信ボタンが `disabled` のままで送信できない。サーバーログにも新規 `mail.sent` は出ない | PASS |
| 5 | （確認ポイント）エラーを解消し同意する | 送信可能な状態に戻る | 項目エラーが消え、同意チェック後に送信ボタンが有効化された（実際の送信は TC 対象外のため行わず） | PASS |

## 補足

- 項目エラーは入力中〜フォーカスアウト時に表示される（パスワードのエラー文言は blur 後に確定表示）。
- 本ケースではアカウントを作成していない（`user-c@example.com` は未登録のまま）。
