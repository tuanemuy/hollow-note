## 補足（Shadow DOM の確認ポイントについて）

- 期待結果（AC-18 のうち本ケースが直接検証する部分）はすべて満たしている。未達なのは testing.md の確認ポイント「詳細の本文領域は Shadow DOM で描画される」のみ。
- 実装は `NoteBody`（`shadowrootmode="open"` の template → `attachShadow` 昇格）を持つが、`NoteDetail` は `content.html` が空/`null` のとき placeholder 段落へ分岐する。本スライスは白紙ノートしか作れない（アップロード・HtmlProcessor は本スライス外）ため、**このスライスの範囲では Shadow DOM 描画を観測できるノートが存在しない**。
- 実装バグではなく、テスト手順書の確認ポイントが本スライスで観測不能というギャップと判断し、FAIL とはしていない。
