## 項目 3: 同じ Google アカウントで繰り返しサインインしても identity 行が増えない

**前提:** 項目 2 の状態からそのまま継続。

| # | 操作 | 期待結果 | 実際に観測した内容（1 回目） | 実際に観測した内容（2 回目） |
|---|------|---------|------------------------------|------------------------------|
| 1 | サインアウト | トップページへ | サインアウトボタン押下後、`/signin` へ遷移して次の操作へ進んだ（トップページ経由を明示確認はしていないが、以降 `/signin` フォームが表示された） | 同上、`/signin` フォームが表示された |
| 2 | `/signin` で「Google で続ける」→ 同意画面で `attach-a@example.com` / `email_verified` ON → 「許可する」 | `付与太郎` としてサインイン成功 | 「許可する」押下後 `get text body` に `付与\n個人` が表示された（アバター表記が「付与」= 付与太郎の省略表示） | 同様に `付与\n個人` が表示された |
| 3 | `/settings/auth` の一覧を確認（Google 行の「追加」日付を含む） | パスワード + Google の 2 件のまま、Google は常に 1 行 | `メールアドレスとパスワード / 有効 / 追加 2026年8月24日 / 解除` と `Google / 有効 / attach-a@example.com で連携済み / 解除` の 2 件のみ | 1 回目と同一のテキスト：`メールアドレスとパスワード / 有効 / 追加 2026年8月24日 / 解除` と `Google / 有効 / attach-a@example.com で連携済み / 解除` の 2 件のみ |

**「追加」日付についての観測:** Google の行には手順書が想定する「追加 YYYY年M月D日」という日付表示は無く、常に `attach-a@example.com で連携済み` という文字列のみが表示された（パスワードの行にのみ `追加 2026年8月24日` の日付が表示される）。そのため「日付が変わらない」という比較は、パスワード行の日付（1 回目・2 回目とも `追加 2026年8月24日` で不変）でのみ行えた。Google 行自体は 1 回目・2 回目とも文字列が完全一致していた。
