# 項目 18: 認証手段管理 — 他のすべての端末からサインアウトする

**結果**: PARTIAL
**対応する受け入れ基準**: AC-16、AC-17 ／ TC-13

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|---------|-----------|------|
| 1 | ウィンドウ1 でサインアウトし `user-a@example.com` / `NewPassw0rd456` でサインイン | サインインできる | `/notes` へ遷移 | PASS |
| 2 | ウィンドウ2 でも `user-a@example.com` / `NewPassw0rd456` でサインインし `/notes` を表示 | 同一ユーザーのセッションが 2 本 | `/notes` を表示 | PASS |
| 3 | ウィンドウ1 の `/settings/auth` で「他のすべての端末からサインアウト」を実行 | 無効にしたセッションが **1 件**であることが表示される | 「他の端末のサインインを解除しました。この端末はそのまま使えます。」とだけ表示。**無効にしたセッション件数は表示されない** | FAIL（件数表示のみ） |
| 4 | ウィンドウ2 を再読み込み | サインアウトされている | `/signin?redirect=%2Fnotes` へリダイレクト | PASS |
| 5 | ウィンドウ1 を再読み込み | サインイン状態が維持されている | `/settings/auth` がそのまま表示（サインイン維持） | PASS |

## 失敗詳細

- **失敗ステップ**: Step 3（件数表示のみ）
- **期待**: 無効にしたセッションが 1 件であることが表示される
- **実際**: 完了メッセージは件数を含まない固定文言（`apps/web/app/components/settings/IdentityList/board.tsx:380`）
- **原因（実装確認）**: ユースケース `packages/core/src/application/identity/signOutOtherSessions.ts:87` の戻り値が `{ revocationAccepted: true }` のみで、無効化したセッション数を返していない。失効は `authEpoch` を進める方式なので、そもそも「無効にしたセッション数」を数えていない設計。件数表示は実装上できない縮退であり、テスト手順書の期待結果が実装（および ADR の epoch 方式）と噛み合っていない。
- **機能面の判定**: 他端末の失効（手順 4）と現端末の維持（手順 5）はどちらも期待どおりで、AC-16 の本質は満たされている。
