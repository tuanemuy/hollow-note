# 項目 9: パスワード再設定 — 入力不一致とリンクからの再設定、他セッションの失効

**結果**: PASS
**対応する受け入れ基準**: AC-10、AC-11、AC-12、AC-16（TC-27 と TC-06）

## 確認ポイント

- 手順 3 の画面に「設定すると、すべての端末のサインインが解除されます。」の説明が出ている。
- 手順 7 の失効は `authEpoch` バンプによるもので、再読み込み 1 回で即反映された。
- 以降ユーザー A のパスワードは **`NewPassw0rd456`**。
